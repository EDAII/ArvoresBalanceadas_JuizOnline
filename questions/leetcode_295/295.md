## A questão

É uma questão sobre implementar uma estrutura de dados que suporte adições de números em um stream contínuo e consultas à mediana em tempo O(log n) por operação. A mediana deve ser o valor médio (para n par) ou o valor central (n ímpar) dos números adicionados até o momento, considerando ordenação implícita.

![295 Questão](../../assets/leetcode_295/question.png)

## Estratégia

Usamos uma árvore AVL onde cada nó também guarda o tamanho da sua subárvore (`size`). Assim conseguimos:

- inserir um número em O(log n) (inserção + rotações AVL),
- encontrar o k-ésimo menor em O(log n) usando `size(left)`.

A mediana é obtida pedindo o elemento de ordem central (ou a média dos dois centrais quando a quantidade é par).

## Algoritmo utilizado

- Inserção: operação padrão de BST com reequilíbrio AVL; após cada inserção atualiza-se `height` e `size`.
- k-ésimo menor: em cada nó verifique `left_size = size(left)`; compare `k` com `left_size+1` para decidir se retorna o nó, vai para a esquerda ou vai para a direita (ajustando `k`).
- `MedianFinder`: mantém `total`; `addNum` insere e incrementa; `findMedian` retorna o elemento central ou a média dos dois centrais.
