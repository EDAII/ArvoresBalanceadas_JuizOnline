## A questão

É uma questão sobre encontrar a mediana de uma **janela deslizante de tamanho fixo `k`** sobre um array de inteiros. A cada passo, a janela se move uma posição para a direita e precisamos computar a mediana dos `k` elementos visíveis no momento.

![480 Questão](../../assets/leetcode_480/480_question.png)

## Estratégia

Usamos a estrutura `SortedList` da biblioteca `sortedcontainers`, que implementa internamente uma **árvore B-tree balanceada**. Isso permite:

- Inserir e remover elementos em **O(log k)**,
- Manter os elementos da janela sempre ordenados,
- Acessar rapidamente os elementos centrais para calcular a mediana.

A mediana é obtida diretamente dos índices centrais da estrutura ordenada em cada nova janela.

## Algoritmo utilizado

- Mantemos uma `SortedList` chamada `window` com os `k` elementos da janela atual.
- A cada iteração:
  - Adicionamos `nums[i]` à janela com `window.add()` em O(log k),
  - Se `len(window) > k`, removemos `nums[i-k]` com `window.remove()` em O(log k),
  - Se a janela tiver exatamente `k` elementos, acessamos os elementos centrais:
    - Se `k` for ímpar: a mediana é `window[k // 2]`,
    - Se `k` for par: a mediana é a média de `window[(k-1)//2]` e `window[k//2]`.

Essa abordagem permite que o deslizamento da janela e a obtenção da mediana sejam feitas de forma eficiente em tempo logarítmico.
